# Code of Conduct

## Our standard

SpiderHead adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as the baseline for participation in this project.

Be respectful, specific, and constructive. Discuss evidence and implementation choices without
attacking people. Harassment, discriminatory language, threats, deliberate disruption, publishing
private information, and sexualized or otherwise unwelcome conduct are not acceptable.

## Scope

This code applies to issues, pull requests, reviews, repository discussions, and public spaces where
someone is representing the project.

## Reporting and enforcement

Report unacceptable behavior privately through the contact methods on the
[maintainer's GitHub profile](https://github.com/PavloSEO). Do not put personal or sensitive details
in a public issue. Content that also violates GitHub policy can be reported through GitHub's own
reporting controls.

Reports will be reviewed promptly and as confidentially as practical. The maintainer may edit or
remove contributions, comments, commits, code, issues, or other material that violates this code,
and may temporarily or permanently restrict participation.
