- `seohead sf --help` now shows the crawl-audit CLI's own help — the subcommands and,
  through `seohead sf <subcommand> --help`, every forwarded flag — instead of a
  placeholder that only said arguments were forwarded. The `sf` tail is now intercepted
  before the top-level parser, the same way `semantics` already was, and the dead
  REMAINDER dispatch is gone. A regression test cross-checks every `sf` flag used in
  the documentation against the help of the subcommand that accepts it.
