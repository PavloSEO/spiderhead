- Crawls on hosts that enforce https no longer spend a redirect hop on every
  http URL. The new opt-in `http.upgrade_to_https` setting rewrites http URLs
  to https before any request — seed, sitemap seeds and discovered links
  alike, in both spider and list modes and in native scans: no redirect is
  recorded for the upgrade, the http and https spellings collapse into one
  page identity, and each page fetched this way carries
  `transport_upgraded: true` in its record (persisted as
  `pages.transport_upgraded`, absent in older scans reads as false). The
  operator opting in is the declaration that the hosts enforce transport
  security; a host without https answers with visible connection errors
  rather than a silent fallback. With the setting off, nothing changes.
