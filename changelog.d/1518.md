- An image-only link now names its destination when the wrapped image carries
  alt text. Links whose visible content is an image used to show an empty
  anchor in link evidence even when the image had a descriptive `alt`, so
  anchor-text review treated every image link as unnamed. The parser now
  records that alt as the link's anchor with an `anchor_source: "alt"` marker
  distinguishing alt-derived anchors from text-derived ones (absent marker =
  text or nothing). A link with visible text keeps its text; a link with
  neither stays empty and keeps feeding the no-anchor-text checks. The marker
  rides the LinkEdge into the scan (`links.anchor_source`), the links export
  and the per-link query views; a scan written before the field reports `null`
  there rather than a false text-derived answer.
