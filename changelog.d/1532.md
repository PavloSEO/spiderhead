- Log bot verification no longer accepts Google Cloud VMs as Google bots. The single
  shared `.googleusercontent.com` suffix — the reverse DNS of ordinary GCP Compute
  instances such as `*.bc.googleusercontent.com` — is replaced by per-family tables
  following Google's published rules: common crawlers (Googlebot and variants,
  GoogleOther, Google-Extended) verify against `*.googlebot.com`; special-case
  crawlers (AdsBot, Mediapartners, APIs-Google, Google-InspectionTool) against
  `*.google.com`; user-triggered fetchers against `*.gae.googleusercontent.com` only.
  A Googlebot user agent from a `*.bc.googleusercontent.com` IP is now reported fake
  with a reason naming the unofficial suffix, instead of passing PTR + forward
  verification as a scanner on GCP would. The `--verify-bots` help, the analyzer
  documentation and `docs/SERVER_LOGS.md` state which domains count as official for
  each family.
