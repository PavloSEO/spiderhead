- Tighten the bundled `SoftwareApplication` rich-result rule to match current Google documentation: `offers` is now required (the docs require `offers.price`, presence is what the local rule engine can check) and at least one of `aggregateRating` or `review` is required via `required_any`, which the engine already supported for `Product`. Previously the rule required only `name` and listed `offers`/`aggregateRating` as recommended, so a block with offers but no rating or review never produced a `STRUCTURED_DATA_RICH_RESULT_REQUIRED_MISSING` finding; verified against developers.google.com/search/docs/appearance/structured-data/software-app. `applicationCategory` and `operatingSystem` stay recommended; rules version bumped to 2026-10-23 (#1413).
- Deliberately not changed: escalating a literal string `BreadcrumbList` `item` and grouping site-wide template warnings. Google's breadcrumb documentation explicitly accepts a plain string URL for `item` ("URL or a subtype of Thing"), so the existing warning severity is correct; warning grouping is a reporting change unrelated to the documented requirements and needs its own design.
