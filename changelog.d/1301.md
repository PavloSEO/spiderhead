- Retained content search now reports bounded occurrences with source-text character offsets, one-based lines, per-document match navigation, and optional redacted six-line windows. Exact URL filtering runs before SQLite ranks retained documents. Full match counts remain visible when the 10,000-offset or 64 KiB record limit truncates returned occurrences, and coverage is partial. Regex searches are unavailable when a wall-clock deadline cannot be enforced; unavailable bodies remain unknown, never absent.
- Indexed search packages are capped at 512 MiB; reaching the limit publishes an explicitly incomplete package with its measured coverage and byte limit.
- Added an offline custom-extraction sample route for caller-supplied HTML. Its optional URL is a label only and does not trigger a fetch; live URL fetching remains an owner decision.
