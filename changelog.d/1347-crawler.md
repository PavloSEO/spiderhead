- Desktop dead surfaces (#1347): the Crawler section now runs an ad-hoc crawl without a project. The address field, the Site/List/Sitemap switch, the URL limit, Start/Stop, the check tabs, address search, the overview counters, the details pane and the CSV/XLSX export are wired to the core `crawl-site --scan-out` and `scan-url-query` commands; the status strip shows the core's own speed, crawled and remaining figures. Nothing starts when the screen opens, and the temporary result is removed on Clear, on the next crawl and when the application quits. The quick-crawl menu entries open the section. The top-bar "Unavailable in this core version" badge is removed. Compare no longer opens in an error state after a project read: a cleared comparison is a neutral prompt to pick two scans, and only a real failure shows the unavailable state.
