- A crawl started deep can now stay in its own subtree. The new
  `scope.start_folder_only` toggle admits only URLs at or below the start
  URL's path folder: a crawl started at `/blog/post` walks `/blog/` and
  everything under it, and links pointing above the folder are counted as
  unfollowed evidence (`excluded` under `outside_start_folder`) exactly like
  any other scope rejection — no hand-written include patterns required. The
  folder is the directory the start URL sits in (a trailing-slash start keeps
  its own folder); a start URL at the host root is refused, because the root
  has no folder to stay below. The setting is recorded per scan in the run
  manifest like every result-affecting setting, and appears in
  `crawl-describe-settings`. With the toggle off nothing changes.
