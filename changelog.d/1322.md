- Scheduled project scans (#1322, core): `schedule.json` in the project directory holds the schedule (weekdays and/or month days, a time window in the site's time zone, enable/disable, competitors, crawl mode `spider`/`sitemap`/`list`, per-run URL and request budgets, politeness delay, and slice mode that resumes the previous partial crawl). It is edited through `schedule-set` / `seo_schedule_set` with `expected_revision`, and `schedule-show` reports the last run and next due window. `schedule-run-due` is a headless entry point that runs only due scans, refuses overlap with a lease, and records every decision in the project journal. `schedule-install` and `schedule-uninstall` write or remove a launchd plist, cron line or Task Scheduler command only when called explicitly.
- Crawl user agents (#1322): presets (`spiderhead`, `googlebot`, `googlebot-desktop`, `googlebot-smartphone`, `bingbot`, `yandexbot`, `yandexmobilebot`, `baiduspider`, `duckduckbot`, `applebot`, `gptbot`, `claudebot`, `perplexitybot`, and desktop and mobile browsers) or one custom string. The default is now `SpiderHeadBot/<version> (+https://github.com/PavloSEO/spiderhead)`, and robots.txt group matching uses the same identity. Sites that matched the former `SEOHEAD-Tools` robots group must name `SpiderHeadBot` in their rules.
