- Scheduled project scans (#1322, core): `schedule.json` in each project directory holds that site's independent schedule (weekdays and/or month days, a time window in the site's time zone, enable/disable, crawl mode `spider`/`sitemap`/`list`, per-run URL and request budgets, politeness delay, user agent and slice-resume state). The owner project can include linked competitors, each with its own cadence and scan policy. Settings are edited through `schedule-set` / `seo_schedule_set` with `expected_revision`; `schedule-show` reports the primary and linked competitors' due state and next run. `schedule-run-due` is a headless entry point that runs only independently due scans, holds process-scoped locks until each run ends, records cancellation state before re-raising it, and journals results or competitor overlap in each affected project. `schedule-install` and `schedule-uninstall` write or remove a launchd plist, cron line or Task Scheduler command only when called explicitly.
- Crawl user agents (#1322): presets (`spiderhead`, `googlebot`, `googlebot-desktop`, `googlebot-smartphone`, `bingbot`, `yandexbot`, `yandexmobilebot`, `baiduspider`, `duckduckbot`, `applebot`, `gptbot`, `claudebot`, `perplexitybot`, and desktop and mobile browsers) or one custom string. The default is now `SpiderHeadBot/<version> (+https://github.com/PavloSEO/spiderhead)`, and robots.txt group matching uses the same identity. Sites that matched the former `SEOHEAD-Tools` robots group must name `SpiderHeadBot` in their rules.
