- Native crawl checks (#1314): image size (`IMG_OVER_KB`) is now measured from the crawl's own image fetches, and sitemap status (`SITEMAP_URL_4XX_5XX`, `SITEMAP_URL_3XX`, `SITEMAP_URL_NON_INDEXABLE`) from the crawl's own fetch of each sitemap-listed URL. A listed URL the crawl never requested is counted as unmeasured, never read as clean. `IMG_MISSING_ALT`, `IMG_MISSING_DIMENSIONS` and `HREFLANG_ERROR` say on a native scan that the crawl does not measure them as the SF export defines them, instead of pointing at an SF filter. Missing hreflang and mixed-content evidence on a native scan is reported as not measured by the native crawl, not as a missing export.
