- A native crawl now measures its own reading level. The new
  `checks.readability` module computes, offline over each page's retained
  content area, the sentence count, average words per sentence, the Flesch
  Reading Ease score (206.835 − 1.015·words/sentences − 84.6·syllables/words,
  English vowel-group syllable heuristic, version
  `flesch-reading-ease.v1`) and the standard band label. The four values are
  stored as per-URL scan fields (`pages.sentence_count`,
  `avg_words_per_sentence`, `flesch`, `readability`), carried into the
  analyzer frame under the same column names an SF export uses — so the
  existing READABILITY_DIFFICULT and LONG_SENTENCES checks now fire on native
  crawls too, with no new check IDs. A page whose content area was not
  retained, or holds no word with a letter, records NULL/"" — unmeasured,
  never a zero that would read as measured-and-easy. Text ratio and word count
  behavior are unchanged.
