- Project checklist coverage now binds streamed audit.v2 reports: `report-build --project` and `audit-workflow --action report` attach the checklist snapshot to xlsx, docx, csv, md and PDF overview output instead of building an unbound report. A scan stopped by its URL budget (`stopped_by_budget`) is accepted as the project's latest audited scan and its report states the limited scope. `report-build --input` accepts the `format` key. `report-build --project --format json` on a streamed audit is refused with an explanation, because the JSON is written verbatim and cannot carry the checklist snapshot.
