- The native crawl now stores the security headers the checks read (`Strict-Transport-Security`, `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`). Before, they were dropped at capture, so a site that sent HSTS was reported as missing it. Set-Cookie headers store only their flags (`secure`, `httponly`, `samesite=`), never the cookie name or value. A security header sent more than once on the same page is reported as `DUPLICATE_SECURITY_HEADER`.
